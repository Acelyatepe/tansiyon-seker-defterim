# Yerel Nunito fontları

Nunito-Regular.ttf (400), Nunito-SemiBold.ttf (600) ve Nunito-Bold.ttf (700)
dosyalarını lisanslarıyla birlikte bu klasöre ekleyin. Ardından pubspec.yaml
içindeki fonts bölümünü etkinleştirin. Tema Nunito ailesini kullanacak şekilde
hazırdır; dosyalar eklenene kadar Flutter sistem fontuna döner.
Font indirme veya google_fonts bağımlılığı yoktur.
